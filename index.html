Street View — clé Google

  1. Va sur console.cloud.google.com, crée un projet et ajoute un compte de facturation.
  2. Active Maps JavaScript API (et Geocoding API pour la recherche d'adresse).
  3. Identifiants → Créer une clé API → restreins-la aux « Sites web » avec l'adresse de cette app.
  4. Mets une alerte de budget à 1 € : l'usage perso reste dans le gratuit.

La clé reste enregistrée uniquement sur ce téléphone.
